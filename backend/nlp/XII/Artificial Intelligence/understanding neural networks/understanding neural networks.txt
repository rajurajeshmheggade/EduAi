COMPONENTS NEURAL NETWORK key components neural network follows: 1. Neurons: • Neurons (also known nodes) fundamental building blocks neural network. • They receive inputs other neurons or external sources. • Each neuron computes weighted sum its inputs, applies activation function, produces output. 2. Weights: • Weights represent strength connections between neurons. • Each connection (synapse) has associated weight. • Weights convey importance feature predicting final output. • During training, neural networks learn optimal weights minimize error. 3. Activation Functions • Activation functions neural networks like decision-makers each neuron. They decide whether neuron should activated (send signal) or not based input receives. • Different types Activation Functions Sigmoid Function, Tanh Function, ReLU (Rectified Linear Unit), etc. (A detailed explanation activation functions beyond scope syllabus) • These functions help neural networks learn make decisions adding non- linearities model, allowing them understand complex patterns data. 4. Bias: • Bias terms constants added weighted sum before applying activation function. • They allow network shift activation function horizontally. • Bias helps account any inherent bias data. 105 5. Connections: • Connections represent synapses between neurons. • Each connection has associated weight, which determines its influence output connected neurons. • Biases (constants) also associated each neuron, affecting its activation threshold. 6. Learning Rule: • Neural networks learn adjusting their weights biases. • learning rule specifies how these adjustments occur during training. • Backpropagation, common learning algorithm, computes gradients updates weights minimize network’s error. 7. Propagation Functions: • These functions define how signals propagate through network during both forward backward passes. Forward pass known Forward Propagation backward pass known Back Propagation. • Forward Propagation forward propagation, input data flows through layers, activations computed. Here, input data flows through network layers, activations computed. predicted output compared actual target (ground truth), resulting error (loss). • Back Propagation Backpropagation essence neural network training. practice fine-tuning weights neural network based error rate (i.e. loss) obtained previous epoch (i.e. iteration.) Proper tuning weights ensures lower error rates, making model reliable increasing its generalization helping network improve its prediction over time. Backpropagation, (short “backward propagation errors”) optimization algorithm used during neural network training. adjusts weights network based error (loss) obtained previous iteration (epoch). Back propagation, gradients propagated update weights using optimization algorithms (e.g., gradient descent). 6.3. FFNNs efficient handling noisy data relatively straightforward implement, making them versatile tools Fig 6.4 various AI applications.
