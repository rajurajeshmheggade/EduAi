Fig 2.6 https://medium.com/@ladkarsamisha123/most-popular-machine-learning-performance-metrics-part-1-ab7189dce555 2.3.1 Evaluation Metrics Classification 1. Confusion Matrix Confusion Matrix table (Fig 2.7) used evaluate performance classification model. summarizes predictions against actual outcomes. creates N X N matrix, where N number classes or categories predicted. Suppose there problem, which binary classification, then N=2 (Yes/No). will create 2x2 matrix. True Positives: case where model predicted Yes real output was also yes. True Negatives: case where model predicted No real output was also No. False Positives: case where model predicted Yes but was actually No. 34 classification regression two fundamental types supervised machine learning algorithms, key difference lies type output they predict: Classification deals discrete categories, which regression predicts continuous values. False Negatives: case where model predicted No but was actually Yes. 2. Precision Recall Precision measures “What proportion predicted Positives truly Positive?” Precision = (TP)/(TP+FP). Precision should high possible. Recall measures “What proportion actual Positives correctly classified?” Recall = (TP)/(TP+FN) 3. F1-score good F1 score means you have low false positives low false negatives, so you’re correctly identifying real threats, you not disturbed false alarms. F1 score considered perfect when 1, while model total failure when 0. F1 = 2* (precision * recall)/(precision + recall) 4. Accuracy Accuracy = Number correct predictions / Total number predictions Accuracy = (TP+TN)/(TP+FP+FN+TN) 2.3.2 Evaluation Metrics Regression 1. MAE Mean Absolute Error sum absolute differences between predictions actual values. value 0 indicates no error or perfect predictions 2. MSE Mean Square Error (MSE) most commonly used metric evaluate performance regression model. MSE mean(average) squared distances between our target variable predicted values.
